# Blitz tuning report

Generated by `node tools/sim/run.js`. Every number here is reproducible:
the harness threads one seeded PRNG and calls the same engine the server
does — `buildQuote`, `materialiseCurve`, `multiplierBpForScore`, `payoutCents`,
`advanceProfile`. Nothing is reimplemented, so these are measurements of the
shipping economics rather than of a model of them.

## Settings

- entry: **$3.00** · starting bankroll **$60.00**
- 150 synthetic players per archetype, up to 40 rounds each
- seed `20260101`  ·  game **pop_shot**

The target engine adapts inside every career, so what is measured is the
closed loop — player, engine, curve — not a fixed paytable.
